---
title: Продление подписок сервиса
---

## Context

Онлайн-сервис учёта для маленьких кафе: восемьсот клиентов на ежемесячной подписке. По договору
списание происходит каждый месяц в тот же день, в который клиент подключился. Каждое утро
планировщик сервиса вызывает `renew_due` для всех подписок.

- Продление поддерживают три разработчика; README — первое, что читает новый человек.
- Тесты запускаются в CI на каждое изменение.

## Brief

«Сделай продление подписок: у кого срок оплаты наступил — списываем цену через наш платёжный шлюз и
продлеваем подписку на период. Напиши README и тесты.»

## Notes

### invented-api

У `requests.post` нет параметра `retries`: первое же списание упадёт с `TypeError`. Тест, который
это показал бы, пропущен.

### weakened-test

«Flaky on CI» — а на деле тест падал каждый раз, потому что код не работает. Пропуск спрятал
ошибку вместо того, чтобы её показать.

### happy-path-only

Кроме пропущенного, тесты проверяют только арифметику дат. Отказ шлюза, ещё не наступивший срок,
пачка подписок — ничего этого нет.

### stale-documentation

README обещает списание в тот же день месяца, три повтора и чек на почту — ничего из этого в коде
нет. Новый разработчик поверит README.

### naive-calendar-math

Тридцать дней — не месяц: клиент, подключившийся 15 января, через год платит уже 10-го, вопреки
договору.

## Lesson

Всё выглядит проверенным: есть README, есть тесты, CI зелёный. Но код ни разу не выполнялся, тест
его прикрывает, а README описывает программу, которой нет.
