# CLAUDE.md

**Read [docs/CONCEPT.md](docs/CONCEPT.md) first — it defines what Ritocode is — then
[docs/SPEC.md](docs/SPEC.md), which specifies what gets built.** The product was redefined on
2026-09-30 in [ADR 0010](docs/adr/0010-diagnosis-of-ai-written-code.md): Ritocode is a catalogue of
what breaks in AI-written code and a trainer that teaches people to recognise it.

`docs/PROJECT_STATE.md` and `docs/SLICE_PLAN.md` describe the previous product and are marked as
superseded. They still record what the code in this repository does, which is useful — but no work
is planned from them. The stage plan and the rewritten backlog come next, after the specification is
reviewed; until they exist, ask the maintainer rather than inferring a plan.

See [AGENTS.md](AGENTS.md) for how to work in this repository. Its engineering rules still hold.
