# MVP Scope

The MVP focuses on delivering the core training experience.

## Required Capabilities

Users must be able to:

1. browse problems
2. open a workspace
3. edit code
4. submit solutions
5. receive evaluation results

## Required Systems

- authentication
- problem catalog
- workspace service
- submission lifecycle
- evaluation pipeline
- sandbox execution

## Out of Scope (MVP)

The following are intentionally excluded:

- real repository contributions
- PR creation
- advanced AI coaching
- complex recommendation systems

These are introduced in later phases.
